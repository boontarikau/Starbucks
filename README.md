# Financial Analysis of Starbucks Corporation
## 📈 Data Sources
Starbucks Fiscal 2024 Results: Q4 and Full Year Report

Industry Benchmarks: IBISWorld, Yahoo Finance

Stock Price Data: Yahoo Finance (yfinance)

## 🧮 Methodology
### 1. Ratio Analysis (Excel)
Evaluated liquidity, profitability, solvency, efficiency, and valuation metrics against industry averages.

### 2. Cost of Capital Models (Excel)
CAPM: Calculated expected return on equity using risk-free rate (3.02%), beta (0.84), and market return (11.25%).

WACC: Weighted average cost of capital considering equity (88%) and debt (12%) components.

### 3. Stock Price Trend Analysis (Manual & Python)
Analyzed price movements from March 2024 to April 2025, linking volatility to leadership changes and strategic shifts.

### 4. Monte Carlo Simulation (Python)
Simulated 100 possible price paths over a 30-day horizon (starting Feb 28, 2025) using geometric Brownian motion to assess short-term risk and uncertainty.

### 5. Facebook Prophet Forecasting (Python)
Forecasted long-term price trends (through 2026) and decomposed seasonality (yearly, weekly) using historical data from 2020.
